About Keyboard

DKY 60HE is a 60% layout, hall-effect gaming keyboard that features magnetic switches instead of mechanical switches, allowing you to execute pressure-sensitive inputs through magnetic sensors.

Features:

Rapid Trigger Technology

- Keys release instantly the moment you move up, allowing faster inputs.

Adjustable Actuation Point

- Allows keys to be registered as early as 0.1mm - 4mm.

Pro-Grade Magnetic Switches

- Comes with pre-lubed Gateron Magnetic Jade switches with deep, satisfying key sounds and instantaneous key response.
